# KidGuard 🛡️
### Smart Screen Time Monitor for Kids

A full-stack app built with React + Cloudflare Workers + D1 Database.

---

## Features
- 👨‍👩‍👧 Parent authentication (register/login)
- 🧒 Kids profile management
- ⏱️ Daily screen time limits
- 📊 Usage reports & weekly charts
- 🎁 Rewards & points system

---

## Tech Stack
| Layer | Technology |
|---|---|
| Frontend | React + TailwindCSS |
| Hosting | Cloudflare Pages |
| Backend | Cloudflare Workers |
| Database | Cloudflare D1 |
| Auth | JWT |
